# 🌴 واحة المنصورية - نظام إدارة المطعم (نسخة PHP)

نظام PHP + SQLite كامل ومستقل - بدون أي إعداد قواعد بيانات خارجي.

## المميزات
- **بدون إعداد**: قاعدة البيانات SQLite تُنشأ تلقائيًا مع أول تشغيل مع كل البيانات الأولية
- **آمن**: كلمات المرور مشفرة (password_hash)، جلسات PHP، حماية CSRF، منع تحميل قاعدة البيانات
- **الإجمالي يُحسب على السيرفر** من أسعار المنيو (لا يمكن التلاعب بالسعر من المتصفح)
- توقيت **Africa/Cairo** في الطلبات والتقارير
- تنبيه **تليجرام** فوري عند كل طلب (اختياري)
- صفحة **فاتورة** للطباعة
- تقارير مبيعات يومية
- صلاحيات: admin / cashier / customer

## متطلبات التشغيل
- PHP 8.0 أو أحدث مع امتدادات: `sqlite3`, `json`, `mbstring`, `curl` (لو عايز تليجرام)
  (معظم الاستضافات فيها كل ده افتراضيًا، وأي تثبيت XAMPP/LAMP كذلك)

## التشغيل على جهازك

### الطريقة 1: سيرفر PHP المدمج (أسهل - للتشغيل المحلي)
```bash
cd wahat_php
php -S localhost:8000 index.php
```
ثم افتح: **http://localhost:8000**

⚠️ مهم: استخدم `index.php` في نهاية الأمر (الـ router) - هو اللي بيمنع تحميل ملف قاعدة البيانات مباشرة.

### الطريقة 2: استضافة حقيقية (Apache / XAMPP)
1. ارفع مجلد `wahat_php` داخل `public_html` (أو `htdocs`)
2. تأكد أن مجلد `data` قابل للكتابة (عادة 755 تكفي مع مالك الموقع)
3. افتح الموقع: `https://yourdomain.com/wahat_php/`

ملف `.htaccess` جاهز داخل مجلد `data` يمنع تحميل القاعدة على Apache.
**Nginx**: أضف للـ config:
```nginx
location ~* /wahat_php/data/ { deny all; }
```

|--------|--------|----------|
| تسجيل الدخول | `?page=login` | الجميع |
| المنيو | `?page=menu` | الجميع (بدون دخول) |
| السلة | `?page=cart` | الجميع |

## إعدادات المطعم والتليجرام
افتح ملف القاعدة `data/wahat.sqlite` بأي أداة (مثل [DB Browser for SQLite](https://sqlitebrowser.org)) وعدل جدول `settings`:

| المفتاح | الوصف |
|---------|--------|
| restaurantName | اسم المطعم على الفاتورة |
| phone | رقم الهاتف على الفاتورة |
| address | العنوان على الفاتورة |
| telegramBotToken | توكن بوت تليجرام (من @BotFather) |
| telegramChatId | الـ Chat ID (من @userinfobot أو getUpdates) |
| whatsappNumber | رقم الواتساب بصيغة دولية بدون + |

## تغيير كلمات المرور (مهم)
كلمات المرور مخزنة مشفرة، فلا يمكن تعديلها يدويًا في القاعدة. أسهل طريقة:

1. سجل دخول بـ admin / admin123
2. افتح `?page=admin` ← تبويب "المستخدمين" ← أضف مستخدمين جدد بكلمات مرور قوية
3. لتغيير كلمة مرور admin نفسها، نفذ مرة واحدة من سطر الأوامر:
```bash
php -r "
\$db = new SQLite3(__DIR__ . '/data/wahat.sqlite');
\$db->exec(\"UPDATE users SET password_hash = '\" . password_hash('كلمة_المرور_الجديدة', PASSWORD_DEFAULT) . \"' WHERE username = 'admin'\");
echo 'تم';
"
```
(أو عبر سكربت صغير: أنشئ ملف `changepass.php` مؤقت بنفس المنطق واحذفه بعد الاستخدام)

## ملاحظات
- ملف القاعدة `data/wahat.sqlite` يُنشأ تلقائيًا مع أول طلب - لا تحذفه أثناء التشغيل (فيه كل الطلبات)
- النسخ الاحتياطي: انسخ ملف `data/wahat.sqlite` فقط
- صفحة الفاتورة عامة لأي شخص يعرف رقم الطلب (رقم الطلب يبدأ بـ ORD-التاريخ-الثانية فصعب تخمينه)
- لو هتنشر على HTTPS (وهذا الأفضل)، فعّل سطر `'secure' => true` في `boot_session()` داخل `lib.php`
